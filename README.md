# ProjectGeoBot

Бот-игра «Угадай город» для сообществ ВКонтакте. Пользователю показываются спутниковые/картографические изображения и фотографии — нужно угадать город. За правильные ответы начисляются очки; цель — набрать 10.

## Возможности
- Генерация изображений города из статических карт Яндекса (режимы «спутник» и «карта») и сборка коллажа из 4 картинок.
- Получение справки о городе из локальной SQLite-базы (`1.db3`) и ссылка на статью в Википедии; при наличии — флаг и герб.
- Полноценный VK-бот для сообществ: Long Poll, клавиатуры, загрузка изображений.

## Технологии
- Python 3, стандартная библиотека (`sqlite3`, `threading`), а также сторонние пакеты: `vk_api`, `requests`, `Pillow`, `beautifulsoup4`/`lxml`, `mtranslate`, `tqdm`.

## Структура (основные файлы)
- `main/main.py` — точка входа бота (обработка событий VK, диалог, начисление очков).
- `main/city_to_dict.py` — выбор целевого города и 3 вариантов-отвлекающих; запуск подготовки изображений.
- `main/image_make_norm.py` — загрузка статических карт/спутников из Яндекс.Карт.
- `main/image_to_black_map_1.py`, `main/corr_img_for_cities.py` — постобработка и сборка итогового изображения.
- `main/info_city.py` — получение текста, фото и атрибутов города из БД.
- Вспомогательные модули: парсинг, утилиты и т. п.

   ```bash
   python -m venv .venv
   # Linux/macOS
   source .venv/bin/activate
   # Windows
   .venv\Scripts\activate
   ```

3. Создайте директорию для изображений: `static/img/` (если её нет).
